한손 홈 - 엄지로만 쓰는 스마트 런처 개인정보처리방침

앱 영문명: ThumbHome
패키지명: com.thumbhome.launcher
시행일: 2026년 9월 19일
최종 수정일: 2026년 10월 3일

한손 홈 - 엄지로만 쓰는 스마트 런처는 사용자의 개인정보를 중요하게 생각합니다. 이 방침은 앱이 접근하는 정보와 그 이용·저장·삭제 방법을 설명합니다.

1. 앱이 접근하는 정보

앱은 런처 기능을 제공하기 위해 기기에 설치된 실행 가능한 앱의 다음 정보를 확인합니다.

  • 앱 이름
  • 패키지명
  • 앱 아이콘

사용자가 Android의 Usage Access(사용정보 접근)를 직접 허용한 경우 다음 정보도 확인합니다.

  • 최근 앱 사용 시각
  • 앱 사용 횟수
  • 앱 사용 지속시간
  • 시간대별 사용 패턴

2. 이용 목적

확인한 정보는 다음 기능에만 이용합니다.

  • 앱 목록 표시 및 앱 실행
  • 원형 메뉴 구성
  • 시간대와 최근성에 기반한 앱 추천
  • 자동 앱 목록 관리
  • 최근 사용 통계 제공

3. Usage Access와 외부 전송

  • Usage Access는 사용자가 직접 허용하는 선택 권한입니다.
  • 이 권한은 Android 설정에서 언제든지 철회할 수 있습니다.
  • 위 정보는 사용자의 기기 내부에서 처리됩니다.
  • 현재 배포 버전은 사용자 정보를 개발자 서버로 전송하지 않습니다.
  • 광고 SDK, Analytics SDK 및 Firebase Analytics를 사용하지 않습니다.
  • 자체 회원가입·로그인 서버와 사용자 데이터 업로드 서버를 운영하지 않습니다.

4. 기기 내부 저장

앱은 기능 제공을 위해 다음 정보를 앱 전용 저장공간에 저장할 수 있습니다.

  • 사용자가 선택하거나 고정한 앱
  • 추천에서 제외한 앱
  • 도크 설정
  • 위젯 배치
  • 제스처 및 표시 설정
  • 추천 학습 패턴
  • 최근 사용 통계

5. 데이터 삭제

  • 앱 설정에서 학습 데이터, 통계 또는 전체 데이터를 초기화할 수 있습니다.
  • Android 설정에서 한손 홈의 앱 데이터를 삭제할 수 있습니다.
  • 앱을 삭제하면 앱 전용 저장공간의 데이터도 삭제됩니다.

6. 타사 위젯

한손 홈은 사용자가 선택한 타사 위젯을 홈 화면에 표시할 수 있습니다. 타사 위젯의 자체 네트워크 통신과 데이터 처리는 해당 위젯을 제공하는 앱의 개인정보처리방침을 따릅니다.

7. 계정

한손 홈에는 회원가입 또는 로그인 기능이 없습니다.
